# Arabic glossary — one term per concept

Round 4, Step 6 (D-474). Every customer-facing Arabic string in BrandSpace is simple, formal,
everyday Arabic — one Arabic for every country — and uses exactly the term below for each concept.
A new string uses these terms; a string that alternates between two terms for one concept is a
defect. The prototype's Arabic wording is not ported (an allowed difference); its Arabic layout is.

| Concept                                   | Approved Arabic term                                                              | English                       |
| ----------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------- |
| Post                                      | منشور (plural منشورات)                                                            | Post                          |
| Draft                                     | مسودة (plural مسودات) — never مسودّة                                              | Draft                         |
| Review                                    | مراجعة; send for review: إرسال للمراجعة; reviewer: مراجِع                         | Review                        |
| Approve a post                            | الموافقة (verb: وافق على); approved: تمت الموافقة; Approvals: الموافقات           | Approve                       |
| Request changes / reject                  | طلب تعديلات / رفض                                                                 | Request changes / Reject      |
| Accept a Brand Brain fact or a strategy   | اعتماد (verb: اعتمد); accepted: معتمدة — a separate concept from approving a post | Accept / Approved (knowledge) |
| Schedule                                  | جدولة (verb: جدوِل); scheduled: مجدول                                             | Schedule                      |
| Publish                                   | نشر; published: منشور / نُشر                                                      | Publish                       |
| Campaign                                  | حملة (plural حملات)                                                               | Campaign                      |
| Brand                                     | العلامة التجارية; short form in running text: العلامة                             | Brand                         |
| Brand Brain                               | عقل العلامة                                                                       | Brand Brain                   |
| Copilot                                   | المساعد                                                                           | Copilot                       |
| Media (library)                           | الوسائط; Media library: مكتبة الوسائط — never الأصول                              | Media                         |
| Workspace                                 | مساحة العمل                                                                       | Workspace                     |
| Channel (a social network a post goes to) | قناة (plural قنوات)                                                               | Channel                       |
| Platform (the social network itself)      | منصة (plural منصات)                                                               | Platform                      |
| Account (a connected social account)      | حساب                                                                              | Account                       |
| AI credits                                | رصيد                                                                              | Credits                       |
| Automation                                | أتمتة                                                                             | Automation                    |
| Calendar                                  | التقويم                                                                           | Calendar                      |
| Strategy / pillar                         | الاستراتيجية / محور (plural محاور)                                                | Strategy / Pillar             |
| Notes                                     | الملاحظات                                                                         | Notes                         |
| Notification                              | إشعار (plural إشعارات)                                                            | Notification                  |
| Team / member / role                      | الفريق / عضو / دور                                                                | Team / Member / Role          |
| Settings                                  | الإعدادات                                                                         | Settings                      |

**The wordmark** is always `BrandSpace`, in Latin, in both languages — never transliterated.
Channel and platform names (Instagram, Facebook, TikTok, LinkedIn, X) stay in Latin too.

**Digits** are Latin (0–9) in both languages; every number, date and money formatter sets
`numberingSystem: 'latn'` (or a `-u-nu-latn` tag).

**Not the interface:** the AI's Egyptian writing dialect for posts (`content.dialect.egyptian`) is
content a customer asks for, and is unchanged.
